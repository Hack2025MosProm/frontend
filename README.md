# Дашборд компаний Москвы

React-приложение для визуализации данных о промышленных компаниях Москвы с использованием интерактивных графиков.

## 🚀 Технологии

- **React 18** - UI библиотека
- **TypeScript** - статическая типизация
- **Vite** - сборка и dev-сервер
- **Ant Design** - UI компоненты
- **Plotly.js** - интерактивные графики
- **React Window** - виртуализация для производительности

## 📦 Установка и запуск

### Предварительные требования
- Node.js 16+ 
- npm или yarn

### Установка зависимостей
```bash
npm install
npm start          # запуск dev-сервера
npm run build      # сборка проекта
```

## ⚙️ Конфигурация

Создайте файл .env в корне проекта:
```bash
VITE_API_URL=https://your-api-domain.com
```
